## Clone the repository

Open a terminal in the directory where you store your repositories and clone it with the following command:

```shell
# HTTPS
git clone https://github.com/FJrodafo/Awesome.git
cd Awesome/
```

```shell
# SSH
git clone git@github.com:FJrodafo/Awesome.git
cd Awesome/
```
